# 🎤 Audio Transcriber Pro

Веб-приложение для транскрибации аудио и видео файлов в текст прямо в браузере!

## 🚀 Быстрый запуск

1. Перейдите по ссылке: `https://[ваш-юзернейм].github.io/[название-репозитория]/`
2. Используйте приложение прямо в браузере
3. На мобильном устройстве можно добавить на главный экран

## 📱 Как добавить на главный экран iOS/Android

### iOS (iPhone/iPad):
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (📤)
3. Пролистайте вниз и выберите "На экран 'Домой'"
4. Назовите "Audio Transcriber"
5. Нажмите "Добавить"

### Android:
1. Откройте приложение в Chrome
2. Нажмите меню (три точки)
3. Выберите "Добавить на главный экран"
4. Подтвердите добавление

## 🎧 Как использовать

### Основные шаги:
1. **Выберите файл** - нажмите на область загрузки или перетащите файл
2. **Настройте параметры** - выберите язык и качество распознавания
3. **Нажмите "НАЧАТЬ ОБРАБОТКУ"** - дождитесь завершения
4. **Скачайте результат** - нажмите кнопку для скачивания файла

### Поддерживаемые форматы:
- **Аудио:** MP3, WAV, M4A, OGG, FLAC
- **Видео:** MP4, AVI, MOV
- **Максимальный размер:** 100MB

### Настройки:
- **Качество:** tiny (быстро), small (рекомендуется), medium/large (максимальное)
- **Язык:** Русский, Английский, Немецкий, Французский, Украинский или автоопределение

## ⚙️ Режимы работы

### 1. Демо-режим (по умолчанию)
- Работает без настройки
- Показывает пример результата
- Позволяет протестировать интерфейс

### 2. Режим с API (для реальной работы)
1. Получите API URL от вашего сервера транскрибации
2. Введите URL в поле "API Настройки"
3. При необходимости укажите токен авторизации
4. Приложение будет отправлять файлы на ваш сервер
